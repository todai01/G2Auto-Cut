# Сдать изменение

1. **Проверки** (минимум): `node --check frontend/script.js`, `python -m py_compile` изменённых
   `.py`, сценарий из `/demo-check` для того, что меняли. Не прошло — не сдаём.
2. **Коммит** только своих файлов: `git add <файлы>` (не `git add -A`: в дереве бывают демо-данные).
   Сообщение — по-английски, что и зачем; в конце строки атрибуции из системного напоминания.
   Модель в сообщение не писать.
3. **Пуш** с повтором при сетевой ошибке:
   ```bash
   B=$(git branch --show-current); for d in 2 4 8 16; do git push -q -u origin "$B" && break; sleep $d; done
   ```
4. **Отправить** пользователю только изменённые файлы — SendUserFile, `display: attach`,
   в подписи — куда положить (`core/…`, `frontend/…`). Много медиа — одним зипом.
   Весь проект зипом — только если попросили.
5. **Ответ** по-русски: что изменилось для пользователя (не код), как проверено, что не проверено.
